# Ashen Citadel (دژ خاکستر)

**نسخه 1.0** — گرافیک حرفه‌ای‌تر + اکشن دفاع

## چه چیزی جدید است
- آسمان ستاره‌دار + شفق + برف متحرک
- ساختمان‌های لایه‌دار با سایه، پنجره نورانی، دود
- دفاع با **پرتابه، ذرات انفجار، عدد آسیب شناور**
- UI شیشه‌ای و دکمه‌های براق‌تر

## اجرا
```bash
git clone https://github.com/Erfan-Mohammadi/ashen-citadel.git
cd ashen-citadel
npx serve .
```

## نکته صادقانه
این هنوز **پروتوتایپ HTML5/Canvas** است. برای گرافیک AAA واقعی (مدل سه‌بعدی، انیمیشن کاراکتر، افکت پیشرفته) باید به **Unity یا Godot** منتقل شود. نسخه 1.0 حداکثر کیفیت ممکن در این موتور وب را هدف گرفته.
