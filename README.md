# Ashen Citadel (دژ خاکستر)

**Midcore Survival Strategy Game** - Mobile Prototype

## درباره بازی

Ashen Citadel یک بازی استراتژی موبایل در سبک Survival Base-Building است.  
بازیکن فرمانده آخرین دژ بازمانده در جهانی یخ‌زده است و باید پایگاه را گسترش دهد، مردم را زنده نگه دارد و با اتحادها بجنگد.

## وضعیت فعلی

این ریپازیتوری شامل:

- پروتوتایپ قابل بازی وب (HTML5 + Canvas + JavaScript)
- سند طراحی کامل بازی (GDD نسخه ۱.۰)

### ویژگی‌های پروتوتایپ فعلی
- سیستم منابع (چوب، سنگ، غذا، زغال، آهن، کریستال)
- سیستم گرمای دژ
- ساختمان‌های قابل ارتقا
- حالت دفاع ساده
- رابط کاربری موبایل‌فرندلی

## اجرا

فایل `index.html` را در مرورگر باز کنید.

```bash
# یا با یک سرور محلی
npx serve .
```
