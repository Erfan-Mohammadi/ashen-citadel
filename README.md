# Ashen Citadel (دژ خاکستر)

**نسخه 0.9** — Mobile Web Demo (QA-fixed)

## بازی کن
```bash
git clone https://github.com/Erfan-Mohammadi/ashen-citadel.git
cd ashen-citadel
npx serve .
```

## اصلاحات v0.9
- Tutorial: «گام ۱ از ۵» (بدون برعکس شدن RTL)
- پاداش مأموریت و هزینه ساختمان به فارسی
- موج ۱ و ۲ دفاع آسان‌تر (دشمن کمتر/کندتر، آسیب قهرمان بیشتر)
- دکمه **ساخت** → باز کردن پنل دژ
- دکمه **اتحاد** → پیام «به‌زودی» (دیگر مرده نیست)
