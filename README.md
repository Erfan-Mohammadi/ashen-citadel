# Ashen Citadel (دژ خاکستر)

**Midcore Survival Strategy** – Mobile Web Prototype  
**نسخه 0.6**

## ویژگی‌ها
- منابع + سیستم گرما
- ساختمان‌های قابل ارتقا با **گرافیک بهبودیافته** (پنجره، در، دودکش، سایه)
- کوهستان و برف متحرک در پس‌زمینه
- قهرمانان (باز کردن، سطح، ستاره)
- دفاع با اسپرایت دشمن و قهرمان
- Tutorial پنج‌مرحله‌ای
- ذخیره / بارگذاری خودکار

## اجرا
```bash
npx serve .
```
سپس `index.html` را باز کنید.
