# Ashen Citadel (دژ خاکستر)

**نسخه 0.8** — Mobile-first Web Prototype

## طراحی موبایل
- تمام‌صفحه روی گوشی (`100dvh` + safe-area برای ناچ)
- نوار پایین شبیه اپ با برچسب فارسی
- دکمه‌های لمسی حداقل ۴۴px
- پنل‌ها به صورت bottom-sheet
- جلوگیری از زوم و overscroll
- Meta برای نصب روی صفحه اصلی (PWA-ready)

## ویژگی‌های بازی
- منابع + گرما + ساختمان
- قهرمانان (باز / سطح / ستاره)
- دفاع موج‌دار
- مأموریت روزانه (دکمه مأموریت)
- Tutorial + Save/Load

## اجرا روی موبایل
```bash
npx serve .
```
آدرس را در مرورگر گوشی باز کن، یا از DevTools حالت Device Toolbar استفاده کن.
