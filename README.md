# Ashen Citadel (دژ خاکستر)

**Midcore Survival Strategy Game** – Mobile Web Prototype

## نسخه فعلی: 0.3

### ویژگی‌ها
- سیستم منابع + گرمای دژ
- ساختمان‌های قابل ارتقا
- سیستم قهرمان (۴ قهرمان، باز کردن با کریستال)
- دفاع واقعی با دشمنان متحرک و قهرمانان
- **ذخیره و بارگذاری خودکار (LocalStorage)** ← جدید در v0.3
- Auto-save هر ۱۵ ثانیه + ذخیره بعد از ارتقا / باز کردن قهرمان / دفاع

### اجرا
فایل `index.html` را در مرورگر باز کنید.

```bash
npx serve .
```

اگر قبلاً بازی کرده باشید، دکمه «ادامه بازی» نمایش داده می‌شود.
