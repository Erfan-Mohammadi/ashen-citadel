# Ashen Citadel (دژ خاکستر)

**نسخه 0.7** – Mobile Web Prototype

## ویژگی‌ها
- منابع + گرما + ساختمان (گرافیک بهبودیافته)
- قهرمانان (باز کردن / سطح / ستاره)
- دفاع با موج
- Tutorial
- Save / Load
- **مأموریت‌های روزانه** ← جدید (دکمه 🗺️)

### مأموریت‌های روزانه
| مأموریت | هدف | پاداش |
|---------|-----|--------|
| ارتقای ساختمان | ۱ بار | چوب + کریستال |
| دفاع موفق | ۱ موج | سنگ + کریستال |
| جمع‌آوری غذا | ۵۰۰ | غذا + آهن |
| تقویت قهرمان | ۱ بار | کریستال |

هر روز ریست می‌شود. دکمه نقشه (🗺️) را بزن.

## اجرا
```bash
npx serve .
```

کد کامل منطق مأموریت‌ها در `js/game.js` و همچنین در workspace محلی artifacts موجود است.
