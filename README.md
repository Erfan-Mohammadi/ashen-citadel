# Ashen Citadel (دژ خاکستر)

**Midcore Survival Strategy Game** – Mobile Web Prototype

## نسخه فعلی: 0.4

### ویژگی‌ها
- سیستم منابع + گرمای دژ
- ساختمان‌های قابل ارتقا
- سیستم قهرمان (۴ قهرمان)
- **ارتقای سطح قهرمان** (تا ۲۰) با غذا / آهن / کریستال
- **ارتقای ستاره قهرمان** (تا ۶★) با بونوس قوی‌تر
- دفاع واقعی با دشمنان متحرک
- ذخیره و بارگذاری خودکار (LocalStorage)

### اجرا
فایل `index.html` را در مرورگر باز کنید.

```bash
npx serve .
```

### کنترل‌ها
- کلیک روی ساختمان‌ها → ارتقا
- دکمه ⚔️ → قهرمانان (باز کردن / ارتقا سطح / ستاره)
- دکمه 🛡️ → دفاع از دژ
