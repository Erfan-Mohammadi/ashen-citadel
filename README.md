# Ashen Citadel (دژ خاکستر)

**نسخه 0.8** — Mobile Web Demo (آماده تست)

## بازی کن
1. ریپو را Clone کن یا فایل‌ها را دانلود کن
2. اجرا:
```bash
npx serve .
```
3. روی گوشی یا با Device Toolbar در کروم باز کن

**GitHub Pages:** بعد از فعال‌سازی، آدرس خواهد بود:
`https://erfan-mohammadi.github.io/ashen-citadel/`
