# Ashen Citadel (دژ خاکستر)

**Midcore Survival Strategy** – Mobile Web Prototype

## نسخه 0.5

### ویژگی‌ها
- منابع + سیستم گرما
- ساختمان‌های قابل ارتقا
- قهرمانان (باز کردن، سطح تا ۲۰، ستاره تا ۶★)
- دفاع با موج‌های دشمن
- ذخیره / بارگذاری خودکار
- **Tutorial پنج‌مرحله‌ای برای بازیکن جدید** ← جدید

### اجرا
`index.html` را در مرورگر باز کنید.

```bash
npx serve .
```

بازیکن جدید بعد از شروع، آموزش کوتاه می‌بیند (قابل رد کردن).
